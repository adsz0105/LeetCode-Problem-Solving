# LeetCode Problem Solving using Java

A collection of solutions to **LeetCode problems** solved using the **Java programming language**. The programs are written to be compatible with both **LeetCode** and **non-LeetCode users**. Each solution can be modified or run as a standalone Java program using any Java-supported IDE or through the **Command Prompt**.

## About
This repository contains Java solutions for various LeetCode problems, covering topics such as: Arrays, Strings, Mathematics, Searching and Sorting, Two Pointers, Hashing, Recursion, Dynamic Programming and other Data Structures and Algorithms. The solutions follow the problem requirements provided by LeetCode while also being adapted for users who want to **take input manually and execute the programs outside LeetCode**.

## Running Programs via Command Prompt
1. Create or open a folder for the Java file.
2. Create a new file and save the code as `ClassName.java` (the filename must match the class name).
3. Open the folder and type `cmd` in the address bar to launch Command Prompt in that directory.
4. Compile the program:
   ```bash
   javac ClassName.java
   ```
5. Run the program:
   ```bash
   java ClassName
   ```
6. Enter the required input when prompted by the program.

## Running Programs Using a Java IDE
The programs can also be run using any Java-supported IDE, such as: IntelliJ IDEA, Eclipse, NetBeans, Visual Studio Code or any other Java-supported IDE. Open the `.java` file in the IDE, compile/run the program, and provide the required input when prompted.

## Requirements
* Java Development Kit (JDK) installed
* Any Java-supported IDE (optional)
* Command Prompt (for CMD execution)

## LeetCode Compatibility
The solutions are based on **LeetCode problem statements** and can be submitted to LeetCode using the required `class Solution` format. For non-LeetCode users, the programs are provided in a **standalone format with `main()` and user input**, allowing them to be compiled and executed locally.
